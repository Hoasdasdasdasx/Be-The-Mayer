# 시장 쟁탈전 — Playtest 0.2

도시의 시장 자리를 놓고 경쟁하는 실시간 멀티플레이 보드게임 프로토타입입니다. Node.js + Express + Socket.IO 기반입니다.

## 가장 쉬운 실행 방법: Replit

1. 아래 ZIP 파일을 내려받습니다.
2. Replit에서 **Import from ZIP / ZIP 업로드** 기능으로 프로젝트를 가져옵니다.
3. 프로젝트가 열린 뒤 패키지 설치가 완료되면 **Run**을 누릅니다. 실행 명령은 `npm start`입니다.
4. 화면 상단의 **Publish/Deploy**에서 웹 서버 앱으로 공개 배포합니다.
5. 공개된 Replit URL을 친구들에게 보냅니다. 방을 만든 뒤 게임 안의 **초대 링크 복사**를 누르면 방 코드가 포함된 참가 링크가 복사됩니다.

## 로컬 실행

Node.js 20 이상에서 다음 명령을 실행합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다. 다른 기기에서 접속하려면 외부에서 접근 가능한 서버 주소에 배포해야 합니다.

## 현재 들어 있는 기능

- 6인 테스트 / 10인 온라인 방
- 참가 코드와 `?room=방코드` 초대 링크
- Socket.IO 실시간 상태 동기화
- 낮과 밤에 각각 장소 선택 및 자원 1장 획득
- 장소별 수용 인원과 턴별 우선권
- 시민(C), 지식인(I), 조직원(O), 상류층(E) 자원 및 지지 점수판
- 계열별 구매 비용이 다른 특수 카드 18종
- 공개 시장, 카드 구매, 카드 사용, 자원 획득·강탈·제거
- 10턴 종료 및 최종 점수 집계
- 참가자별 특수 카드 손패 비공개
- 연결이 끊긴 참가자의 차례 자동 건너뛰기

## 첫 테스트 규칙

- 6인 방: 특수 카드 18종 × 각 2장, 공개 시장 4장
- 10인 방: 특수 카드 18종 × 각 3장, 공개 시장 5장
- 낮과 밤 각각 자원 1장 확보
- 밤마다 특수 카드 최대 1장 구매, 손패 최대 4장
- 사용한 권력층 자원은 지지 포인트에서도 차감
- 10번째 밤 종료 시 권력층 자원 합계가 가장 높은 플레이어 승리

## 테스트 버전의 제한

- 방과 게임 상태는 서버 메모리에 저장됩니다. 서버가 재시작되면 방과 게임 상태가 초기화됩니다.
- 계정/로그인, 영구 저장, 비공개 방 비밀번호, 채팅, 실시간 관전 기능은 아직 없습니다.
- 카드 밸런스는 초기 테스트용이며 실제 플레이 결과에 따라 조정해야 합니다.
