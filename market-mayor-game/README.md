# Be The Mayor — 시장 쟁탈전

도시의 시장 자리를 놓고 경쟁하는 실시간 멀티플레이 보드게임 프로토타입입니다. Node.js + Express + Socket.IO 기반입니다.

## 카드 중심 UI

현대 선거 캠프를 배경으로 후보 현황, 단계별 게임판, 공개 시장, 내 손패를 배치했습니다. 별도의 프레임워크 없이 작은 Node.js 스크립트로 스타일과 UI 코드를 HTML 하나에 포함합니다.

- 손패는 최대 4장의 특수 카드만 표시합니다. 클릭·키보드 Enter로 상세를 확인하고, 대상 지정 후 사용합니다. Escape로 선택을 취소합니다.
- 사용할 수 없는 카드도 설명을 읽을 수 있습니다. 실행 버튼은 비활성화되며 구체적인 이유가 표시됩니다.
- 시장 카드를 선택한 뒤 비용을 확인하고 구매합니다. 서버 상태가 도착하기 전에는 자원이나 손패를 변경하지 않습니다.
- 다른 후보의 갱신에도 유효한 카드 선택과 대상을 보존합니다. 요청 중 중복 입력을 잠그고, 재접속 때 기존 방에 다시 참가합니다.
- 낮·밤 테마, 후보 강조, 접이식 선거 기록, 규칙·설정·초대 모달, 모바일 후보 패널을 제공합니다.
- 계열별 일러스트는 자체 SVG로 구성합니다. 외부 이미지·폰트 네트워크 요청이 필요 없습니다.
- 설정에서 애니메이션을 줄일 수 있고 운영체제의 모션 감소 설정도 따릅니다.

카드 비용·효과·사용 시점은 서버에서 전달하는 카드 정의를 그대로 사용합니다. 변경 전 계약은 [UI 계약](docs/ui-contract.md), 검증 범위는 [검증 기록](docs/ui-validation.md)을 참고하세요.

## 가장 쉬운 실행 방법: Replit

1. 아래 ZIP 파일을 내려받습니다.
2. Replit에서 **Import from ZIP / ZIP 업로드** 기능으로 프로젝트를 가져옵니다.
3. 프로젝트가 열린 뒤 패키지 설치가 완료되면 **Run**을 누릅니다. 실행 명령은 `npm start`입니다.
4. 화면 상단의 **Publish/Deploy**에서 웹 서버 앱으로 공개 배포합니다.
5. 공개된 Replit URL을 친구들에게 보냅니다. 방을 만든 뒤 게임 안의 **초대 링크 복사**를 누르면 방 코드가 포함된 참가 링크가 복사됩니다.

## 로컬 실행

Node.js 20 이상에서 다음 명령을 실행합니다.

```bash
npm ci
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다. 다른 기기에서 접속하려면 외부에서 접근 가능한 서버 주소에 배포해야 합니다.

`PORT` 환경 변수로 포트를 변경할 수 있습니다. 기본 실행에는 별도의 키나 데이터베이스가 필요하지 않습니다.

`npm start`는 먼저 `npm run build`를 실행합니다. 화면 수정은 `client/index.template.html`, `public/styles.css`, `public/ui.js`, `public/app.js`에서 하고, 생성된 `public/index.html`은 직접 수정하지 않습니다. 서버 실행 중 수정했다면 `npm run build` 후 브라우저를 새로 고치세요.

`public/index.html`만 내려받거나 미리보기로 열어도 스타일이 표시됩니다. Socket.IO 서버가 없으면 방 생성·참가는 비활성화되고 안내가 표시됩니다. 실제 멀티플레이에는 `npm start`로 실행한 게임 서버가 필요합니다.

## 개발 검증

```bash
npm run build
npm run check
npm test
npx playwright install chromium
npm run test:browser
```

브라우저 테스트는 별도 3100 포트에서 실제 서버를 시작하고 종료합니다. 시스템 Chromium이 `/usr/bin/chromium`에 있으면 자동 사용하며, 다른 위치는 `CHROMIUM_PATH`로 지정할 수 있습니다. 테스트 중 기존 개발 서버의 방 상태를 사용하지 않습니다.

`npm test`는 실제 서버 코드를 격리된 VM에서 실행하여 모든 카드 효과와 게임 진행을 검증합니다. 브라우저 테스트는 실제 서버의 두 브라우저 세션 검증과, 서버에서 생성한 상태를 전달하는 결정적 UI 검증을 구분합니다. 화면 캡처는 `test-results/`에 생성됩니다.

## 현재 들어 있는 기능

- 6인 테스트 / 10인 온라인 방
- 참가 코드와 `?room=방코드` 초대 링크
- Socket.IO 실시간 상태 동기화
- 낮과 밤에 각각 장소 선택 및 자원 1장 획득
- 장소별 수용 인원과 턴별 우선권
- 시민(C), 지식인(I), 조직원(O), 상류층(E) 자원 및 지지 점수판
- 계열별 구매 비용이 다른 특수 카드 18종
- 공개 시장, 카드 구매, 카드 사용, 자원 획득·강탈·제거
- 10턴 종료 및 최종 점수 집계
- 참가자별 특수 카드 손패 비공개
- 연결이 끊긴 참가자의 차례 자동 건너뛰기

## 첫 테스트 규칙

- 6인 방: 특수 카드 18종 × 각 2장, 공개 시장 4장
- 10인 방: 특수 카드 18종 × 각 3장, 공개 시장 5장
- 낮과 밤 각각 자원 1장 확보
- 밤마다 특수 카드 최대 1장 구매, 손패 최대 4장
- 사용한 권력층 자원은 지지 포인트에서도 차감
- 10번째 밤 종료 시 권력층 자원 합계가 가장 높은 플레이어 승리

## 테스트 버전의 제한

- 방과 게임 상태는 서버 메모리에 저장됩니다. 서버가 재시작되면 방과 게임 상태가 초기화됩니다.
- 계정/로그인, 영구 저장, 비공개 방 비밀번호, 채팅, 실시간 관전 기능은 아직 없습니다.
- 카드 밸런스는 초기 테스트용이며 실제 플레이 결과에 따라 조정해야 합니다.
